# Checkpoints

The final `best.pt` files are included in the full `QDD-Fuse.tar.part-*` release archive, not committed directly to the GitHub source tree.

After extracting the archive, the expected paths are:

```text
checkpoints/mosi/best.pt
checkpoints/mosei/best.pt
checkpoints/simsv2/best.pt
```

SHA256 checksums are recorded in `results/checkpoint_sha256.txt`.
